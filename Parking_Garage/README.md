# Parking Garage Management System (C++)

A console-based parking garage simulation written in modern C++.  
The project models real-world garage behavior including vehicle entry, ticketing, rate selection, and exit billing.

## Features
- Vehicle entry using license plate with automatic ticket assignment
- Exit by **license plate** or **ticket ID**
- Support for multiple vehicle types:
  - Car
  - Motorcycle
  - Truck
- Configurable pricing:
  - Hourly rate with daily cap
  - Flat day pass
- Rate selection at **entry** (stored and applied at exit)
- Capacity tracking and occupancy status
- Robust input validation to prevent invalid menu selections or crashes
- Simulated time advancement for testing billing logic
